BATTLE ZONE — COMPLETE VS CODE BROWSER PROJECT

RUN IT:
1. Extract this ZIP.
2. Open VS Code > File > Open Folder > select BattleRoyale_VSCode.
3. Install the Live Server extension if needed.
4. Right-click index.html > Open with Live Server.
5. Click ENTER BATTLE. Click the game window if the mouse is not captured.

IMPORTANT: Internet is required to load Three.js from its CDN. Use desktop Chrome or Edge with WebGL enabled.

CONTROLS:
- WASD: move / drive / steer boat
- Mouse: aim
- Left click: fire your gun
- Shift: sprint
- R: reload
- E: enter or exit a nearby car or boat
- Esc: release mouse
- Enter: restart after defeat

FEATURES IN THIS VERSION:
- 3D arena with buildings, trees, rocks, road, cars, enemy bots and player shooting.
- Player gunshot sound.
- Enemy gunshot sound when enemies attack, with distance-based volume.
- Engine sound while driving a car; pitch/volume changes with speed.
- Boat engine sound while steering the boat.
- River, crossing bridge and RIVER CROSSING signboard.
- A controllable boat near the river. Walk up to it and press E.
- Tactical minimap on the right showing player, enemies, cars, boat, river and buildings.
- Arena boundary fence and BATTLE ARENA signboard.

This is a local single-player prototype, not a complete BGMI clone. Online multiplayer and mobile touch controls are not included. Audio starts after the first user interaction because of browser audio restrictions.
